# WildTales

WildTales is a mobile application designed to encourage children and families to explore outdoor environments through interactive, location-based journeys.

The project explores how digital technology can support outdoor discovery without requiring users to continuously interact with their phones. Users can follow journeys, discover landmarks, complete activities, collect rewards and track their progress while exploring real-world locations.

## Key Features

- Location-based journeys and landmark discovery
- Interactive maps and geolocation
- Offline journey support
- Parent and child profiles
- Achievement tracking
- Puzzle and artwork reward system
- Camera-based activities
- Educational landmark content
- Audio narration and content delivery
- Parental controls

## Project Concept

WildTales was created around the question:

> How can technology encourage families to explore the outdoors while reducing the need for continuous phone interaction?

The application provides structured journeys that guide users between landmarks. Children can complete activities and discover educational content while parents can monitor progress through dedicated profiles and controls.
