# WildTales

WildTales is a mobile application concept designed to encourage children and families to explore outdoor environments through interactive journeys, landmark discovery and rewards.

The project explores how digital technology can support outdoor activity without requiring users to continuously interact with their phones.

## Key Features

- Location-based journeys
- Landmark discovery
- Offline mode
- Child and parent profiles
- Parental controls
- Achievement tracking
- Puzzle and artwork rewards
- Interactive educational content
